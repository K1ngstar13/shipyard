SHIPYARD 2.4.1

Edit your game, listing, and artwork.

Double-click Start Shipyard.command on your Mac. It stops verified older Shipyard processes and closes their separate Terminal windows, builds this version, then opens the correct panel.

Check that the panel header says 2.4.1. Keep the new Terminal window open while using Shipyard. If macOS asks for permission to control Terminal, allow it so older Shipyard windows can close. In a shared window, the launcher exits the old Shipyard tab's shell and leaves other tabs alone.

Update your existing Block Pals entry to Block Pets

  1. Open the game in Shipyard and choose Edit listing. The editor opens at Listing (step 4).
  2. Click 1 · Game and choose the updated HTML. This package includes it at games/block-pals/www/index.html. Open the included Block Pets game.
  3. Shipyard reads Block Pets from the uploaded title. You can change the name and every listing field on 4 · Listing. Manual edits are retained.
  4. On 2 · Icon, design or upload an icon. On 3 · Screens, capture new screens or upload PNGs. Remove unwanted screens or use the arrows to reorder them. Old artwork is cleared when the game file changes.
  5. Continue through Listing, Privacy, and Price to Review. Every review field has an Edit button. Continue advances one step at a time.
  6. Choose Save edits to GitHub without a build to save just the changes. Or select App Store only on Price and Send to my phone on Review to save and start TestFlight.

Keep the existing folder block-pals and App ID elevatr.llc.blockpals. They connect this game to your Apple app record; the public name is Block Pets.

Drafts

Use Save draft at any step. Edits also save automatically on this browser, including uploaded game files, the icon, and selected screenshots. Closing and reopening the editor restores the draft. A saved review reopens at Listing rather than jumping to step 7. Drafts do not start builds or send anything to a store.

Update your GitHub build code

The local launcher runs this downloaded version. GitHub Actions runs the code in your repository. In GitHub Desktop, copy this release's code into your Shipyard repository, preserving your existing games/ and shipyard.config.json, then commit and push. Upload the included Block Pets HTML through the editor to update that game's source, metadata, and artwork together.

# One-line pitches

The line you post with the video. Write three, use the one that makes a stranger want to watch.

## Shapes that work

**The odd specific.**
> I made an idle game where the only thing that happens is a duck gets more hats.

**The constraint.**
> A sudoku-like puzzle where every color makes its own keyboard sound. No timer, no score.

**The honest small.**
> Twelve levels, one pet to feed, no ads. That's the whole game.

## Shapes that don't

- "Check out my new game!" — gives nobody a reason.
- "The ultimate casual gaming experience" — says nothing, sounds like an ad.
- "Please download and rate 5 stars" — reads as begging and gets downvoted.

## Where to post

| Place | What lands there |
| --- | --- |
| r/incremental_games | Idle and clicker games. Genuinely welcoming to solo devs. |
| r/WebGames | The browser version, before the store version. Good early feedback. |
| r/AndroidGaming, r/iosgaming | Launch posts with a video. Read the self-promo rules first. |
| r/puzzles, r/nonograms | Only for puzzle games, and only if you're a real participant there. |
| TikTok, Reels | 10–20 seconds, no talking, satisfying moment on loop. |
| Bluesky, Mastodon | Build in public over weeks; the launch post then lands on people who know you. |
| Genre Discord servers | Ask the mods first. A #self-promo channel post is fine; a DM blast is not. |

Rule for all of them: participate somewhere for a while before you post your own thing. Communities can tell.
